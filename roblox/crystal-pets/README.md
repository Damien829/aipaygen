# Crystal Pets Simulator

A complete Roblox simulator: mine crystals, hatch pets, unlock zones, rebirth, and collect daily rewards.
The map and all UI are generated by code, so you never have to build anything in Studio.

## Run it (10 minutes)

1. Install [Roblox Studio](https://create.roblox.com) and create a **Baseplate** place.
2. Install [Rojo](https://rojo.space/docs/v7/getting-started/installation/) (`aftman install` in this folder works too) and its Studio plugin.
3. In this folder: `rojo serve`. In Studio, click the Rojo plugin, then **Connect**.
4. In Studio: **Home > Game Settings > Security > Enable Studio Access to API Services** (so saving works while testing).
5. Press **Play**.

To ship a standalone file: `rojo build -o CrystalPets.rbxl`.

Purchases are idempotent: the PurchaseId is saved before the receipt is granted.

## Revenue features built in

- **Crystal Club subscription** (recurring revenue). Create it under Monetization > Subscriptions and paste its ID (looks like `EXS-...`) into `Config.Subscription.Id`.
- **Contextual offers:** a small card offers the Starter Pack after 90 seconds, a coin pack when a player can't afford an egg, and the 2x Boost right after a rebirth. Offers only show for products whose ID is set, and at most once every 3 minutes.
- **Friends bonus:** +10% coins per friend in the same server (max +50%) encourages invites and group play.
- **Shiny pets, limited-time eggs and trails** keep players hatching and buying.

## What's inside

| File | Job |
|---|---|
| `src/shared/Config.luau` | All balance numbers, pets, eggs, zones, pass/product IDs |
| `src/server/DataService.luau` | DataStore with retries; refuses to overwrite on a failed load |
| `src/server/Economy.luau` | Coins, multipliers, rebirth, daily streak, batched state sync |
| `src/server/Pets.luau` | Weighted hatching (Lucky pass boosts odds), equip logic |
| `src/server/Mining.luau` | Server-validated mining plus Auto Collect |
| `src/server/Cosmetics.luau` | Trail cosmetics (coin sink plus Robux trails) |
| `src/server/Monetization.luau` | Game passes and `ProcessReceipt` |
| `src/server/World.luau` | Procedural map, crystals, eggs, unlock pedestals |
| `src/client/UI.client.luau` | HUD, Pets, Shop, Rebirth and Daily panels, hatch popup |
| `src/client/TrailRenderer.client.luau` | Draws equipped trails on every player |
| `src/client/PetRenderer.client.luau` | Pets follow every player (rendered client-side) |

## Retention and revenue loop

Mine, then hatch, then equip, then earn faster, then unlock a zone, then hatch a better egg, then rebirth. The daily streak brings players back.
Revenue levers: passes (`2x Coins`, `Auto Collect`), consumable coin packs and the timed boost, and
`Lucky Hatch`. Players who use Auto Collect also stay longer, which helps engagement-based creator rewards (check the Creator Hub for the current program).

## Tuning

- Shiny pets: any hatch has a 2% chance (5% with Lucky Hatch) to be a Shiny with 2.5x the multiplier. Change `ShinyChance` in `Config.luau`.

- Too slow or fast? Change `CrystalValue`, egg `Cost`, and zone `Cost` in `Config.luau`.
- More content = more retention: add pets, eggs and zones by copying the existing entries.
- Ship updates weekly. Fresh updates are what Roblox's recommendations reward.
- Add event eggs and a limited-time pet later for a quick revenue spike.

## Known limits

- Built without access to Studio, so run a quick playtest first and report anything odd.
- Pets are colored orbs with emoji icons. Swap `makePet` in `PetRenderer.client.luau` for real
  meshes or models when you have art.
- Add a thumbnail and icon, and write a clear game description before publishing.
