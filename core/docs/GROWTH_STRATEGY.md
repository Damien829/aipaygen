- We remove prompt engineering. Call /sentiment, get structured output.
- We bundle scraping, data tools, workflows. They're inference-only.
- We start at $0.50. They start at $5.
- We support MCP natively. They're API-only.

### vs Replicate/Together/Groq
- They host models. We provide complete tools.
- They require ML knowledge. We're a REST API.
- We have web scraping, agent marketplace. They don't.

## What NOT to Do

- Don't pay for ads (no budget, wrong stage)
- Don't target consumers (not your market)
- Don't build more features (you have enough, distribute what you have)
- Don't compare yourself to ChatGPT/Claude.ai (different market)
- Don't use hype words (game-changing, revolutionary, 250+ tools)
- Don't spread across too many audiences simultaneously
