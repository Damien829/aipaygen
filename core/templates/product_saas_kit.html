FAQ

What language / framework is this?

Python 3.11+ with Flask. Templates use Jinja2. Database is SQLite by default (easily swappable to PostgreSQL). Frontend is vanilla HTML/CSS/JS with the Apple-inspired design system.

Can I use this for commercial projects?

Yes. You get a full commercial license. Use it for client projects, your own SaaS, or anything else. No attribution required.

How do I deploy it?

Includes a deploy.sh script for any Linux server. Works great on a Raspberry Pi 5, VPS, or any cloud provider. Cloudflare Tunnel included for zero-config HTTPS.

Do I need a Stripe account?

Yes. A free Stripe account is required for billing. The kit includes test mode configuration so you can develop locally without processing real payments.
